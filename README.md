# 🌦️ Weather App (React.js)

A simple and responsive **Weather Application** built with **React.js** that allows users to search for any city and view real-time weather details using a weather API.

## 🚀 Live Demo

🌐 **Try the application here:** [Weather App by Mihir](https://weather-app-by-mihir.netlify.app/)

---

## 🚀 Features

- 🌍 Search weather by city name.
- 📡 Real-time data fetched from a Weather API.
- 🌡️ Displays **temperature, humidity, wind speed, and weather conditions**.
- 🎨 User-friendly and responsive UI.
- ⚡ Fast performance with React.js.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, CSS
- **API:** OpenWeatherMap API (or similar)
- **Tools:** Git, GitHub
- **Deployment:** Netlify

---

## 📂 Project Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Weather-App.git
cd Weather-App
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
